# Dulcemente

Sitio web estático para una pastelería de decoración artesanal. Presenta pastelitos personales, mini cakes y ponqués para celebraciones, junto con un formulario guiado de pedido, cálculo del abono estimado y envío de la solicitud por WhatsApp.

## Desarrollo local

Requiere Node.js 22.13 o superior.

```bash
npm install
npm run dev
```

Para validar la versión de producción:

```bash
npm run build
```

## Configuración antes de vender

- Sustituir el enlace genérico de WhatsApp por el número comercial.
- Ajustar precios, domicilio, horarios y correo de contacto.
- Conectar el enlace de pago seguro de la cuenta del negocio para recibir abonos reales.
- Reemplazar las imágenes de referencia por fotografías propias cuando estén disponibles.
